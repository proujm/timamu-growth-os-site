Политика конфиденциальности

TiMaMu Growth OS

Какие данные используются

С разрешения владельца канала — статистика и сведения о собственном канале TiMaMu (через YouTube Data API и YouTube Analytics API, доступ только на чтение). Для планирования роликов — общедоступные данные YouTube о видео на выбранные темы и каналах, выбранных владельцами.

Где хранятся

Только на домашнем сервере владельцев. Данные не передаются и не продаются третьим лицам и не используются для рекламы.

Сколько хранятся

Общедоступные данные других каналов хранятся не дольше, чем разрешают правила YouTube API Services (до 30 дней), затем удаляются или обновляются. Данные собственного канала — пока владельцы пользуются приложением.

Как отозвать доступ и удалить данные

Доступ можно отозвать на странице разрешений Google: myaccount.google.com/permissions. По запросу на proujm@gmail.com все данные удаляются в течение 7 дней.

YouTube и Google

Приложение использует YouTube API Services. Условия использования YouTube: www.youtube.com/t/terms. Политика конфиденциальности Google: policies.google.com/privacy.

Privacy Policy

TiMaMu Growth OS

What data is used

With the channel owner's authorization — statistics and information about the owners' own TiMaMu channel (via the YouTube Data API and YouTube Analytics API, read-only access). For video planning — publicly available YouTube data about videos on chosen topics and about channels selected by the owners.

Where it is stored

Only on the owners' home server. The data is not shared with or sold to third parties and is not used for advertising.

How long it is kept

Publicly available data of other channels is kept no longer than the YouTube API Services policies allow (up to 30 days), after which it is deleted or refreshed. Data of the owners' own channel is kept for as long as the owners use the app.

Revoking access and deleting data

Access can be revoked on the Google permissions page: myaccount.google.com/permissions. On request to proujm@gmail.com, all data is deleted within 7 days.

YouTube and Google

This app uses YouTube API Services. YouTube Terms of Service: www.youtube.com/t/terms. Google Privacy Policy: policies.google.com/privacy.
